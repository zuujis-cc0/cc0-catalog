# CC0 catalogue

**Every asset mirrored in [zuujis-cc0](https://github.com/zuujis-cc0), grouped by what it is.** 8,407 assets from Poly Haven, ambientCG, OpenGameArt, all public domain under [CC0](https://creativecommons.org/publicdomain/zero/1.0/): use them in any game, free or paid, no credit needed.

Each topic page shows every asset with a picture; click one to open its folder, where every file can be opened and saved on its own. The mirror repositories fill themselves, so a few assets may still be arriving. Updated every day from [cc0-mirror](https://github.com/zuujis-cc0/cc0-mirror) (last: 2026-11-26).
